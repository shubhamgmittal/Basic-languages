Go Language Setup Linux

About Go Language

Go is a fast and efficient programming language used for backend development, DevOps tools, and cloud computing.

Prerequisites

  • Linux operating system (Ubuntu, Debian, Fedora etc.)
  • Terminal access
  • Internet connection

Required Software

  • Go Programming Language
  • Visual Studio Code
  • Terminal

Download Visual Studio Code

Here is the installer matching your operating system.

  • Linux (.deb)
    Download VS Code for Debian/Ubuntu
  • Linux (.rpm)
    Download VS Code for Fedora/RHEL


Here is how it should look after installation


Installation Steps

For Ubuntu / Debian:

                sudo apt update
                sudo apt install golang-go

Check installation:

                go version

Best VS Code Extensions

  • Go (Official Extension)
  • Code Runner
  • Error Lens
  • GitLens

Basic Go Program

        package main
        
        import "fmt"
        
        func main() {
            fmt.Println("Hello Go from Linux!")
        }

Run program:

        go run main.go

Conclusion

Go is now installed on your Linux system. You can start building CLI tools, APIs, and backend applications.
